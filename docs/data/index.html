Columns

idShort ID. Same as the id in prices.json.
serviceCompany or service name.
planPlan name we use. Some names are shortened.
groupOur category, such as TV or Games.
price_usdList price in US dollars, before tax. For new US subscribers.
billing_periodmonth or year. A yearly price is never divided by 12.
source_urlThe company page the price was read from.
checkedDate we last checked that page (YYYY-MM-DD).
noteShort caveat, if the page had one. Often empty.
launch_yearYear of the launch price. Empty if we have none.
launch_price_usdLaunch price in US dollars. Empty if we have none.
launch_billing_periodmonth or year, for the launch price.
launch_source_urlPage that states the launch price.

Where the prices come from

Each current list price was read from the company's own page. We list new US subscriber prices before tax, and leave out intro offers and student prices.

A script re-fetches every source page and flags changes. A person then updates the data file. We last checked on Nov 25, 2026.

Prices change. Treat each row as true on its check date.
